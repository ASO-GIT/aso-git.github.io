# Presentaciones del Curso - Ampliación de Sistemas Operativos

Repositorio de presentaciones del curso **Ampliación de Sistemas Operativos** de la **Universidad de Alcalá - Patrimonio de la Humanidad** (Curso 2025-2026).

Este repositorio contiene las presentaciones en formato Reveal.js publicadas mediante GitHub Pages.

## 📚 Presentaciones Disponibles

- **[S9: PaaS, Cloud Run Functions y Pub/Sub](S9/index.html)**
  - Introducción a Platform as a Service
  - Cloud Run Functions
  - Pub/Sub básico
  - Arquitectura event-driven

- **[S11: Fundamentos de Docker y Desarrollo Local](S11/index.html)**
  - Conceptos de contenedores
  - Dockerfiles y mejores prácticas
  - DevContainers
  - Docker Compose con PostgreSQL

- **[S12: Docker en CI/CD y Cloud Run](S12/index.html)**
  - Registros de imágenes
  - Cloud Build para CI/CD
  - Cloud Run
  - Secret Manager

## 🚀 Uso Local

Para visualizar las presentaciones localmente:

1. Clonar el repositorio:
```bash
git clone git@github.com:ASO-GIT/aso-git.github.io.git
cd aso-git.github.io
```

2. Abrir las presentaciones en un navegador:
   - Abrir `index.html` para ver el índice
   - O abrir directamente `S9/index.html`, `S11/index.html`, `S12/index.html`

## 📖 Navegación en las Presentaciones

- **Flechas:** Navegar entre slides
- **Espacio:** Siguiente slide
- **S:** Abrir vista del presentador (con notas)
- **F:** Pantalla completa
- **ESC:** Vista general de todas las slides
